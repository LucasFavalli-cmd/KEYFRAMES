Animações utilizando Keyframes



O que é @keyframes?

O @keyframes é uma regra do CSS usada para criar animações, permitindo definir como um elemento deve se comportar em diferentes momentos ao longo do tempo. Em vez de apenas mudar de um estado para outro de forma imediata, ele cria uma sequência de etapas intermediárias, como início, meio e fim da animação, usando porcentagens como 0%, 50% e 100%. Dentro dessas etapas, você define quais propriedades do elemento vão mudar, como posição (transform), cor (background-color), tamanho (scale) ou outros estilos. Assim, o navegador entende como interpolar esses valores e criar uma transição suave entre eles. Para que a animação funcione de fato, ela precisa ser aplicada ao elemento através da propriedade animation, onde você define coisas como duração, repetição e velocidade. Isso permite criar efeitos como movimento, rotação, mudanças de cor e loaders de forma contínua e controlada.


Cores e imagens

Texto Neon

NEON

Textshadow 0 0 0

Criado usando text-shadow, que adiciona várias camadas de sombra colorida ao texto, simulando um brilho luminoso. Ao combinar diferentes níveis de blur e cores fortes, como ciano ou roxo, o texto ganha um efeito de luz intensa. Esse efeito pode ser animado com @keyframes, fazendo o brilho piscar ou pulsar, e a propriedade animation controla o tempo e a repetição, deixando o neon mais realista e dinâmico.

Cores

background-color: #000000

Utiliza-se o @keyframes para alterar o background-color em diferentes etapas da animação, criando uma transição automática entre cores. Depois, a propriedade animation controla o tempo, a velocidade e a repetição da animação.

Slides

translateX (-300px)

Um slide em CSS é feito colocando as imagens em linha com display: flex e usando @keyframes com translateX() para mover as imagens de um lado para o outro. Depois, a propriedade animation controla o tempo e faz a transição acontecer automaticamente em loop, criando o efeito de carrossel.


Movimento e Animações

Movimento

translate (x/y)

Para mudar a cor de um bloco, você define valores de background-color em etapas como 0%, 50% e 100%, criando uma transição entre cores. Depois, aplica essa animação ao elemento usando a propriedade animation, que controla o tempo, a repetição e o comportamento da mudança, fazendo o bloco trocar de cor automaticamente de forma contínua ou em loop.

Botão Pulsando

transform: scale()

Um botão pulsando no CSS é criado usando @keyframes para variar o tamanho do elemento com transform: scale(), fazendo ele crescer e diminuir de forma contínua. Depois, a propriedade animation define o tempo e a repetição, criando um efeito de pulsação suave e constante que chama atenção do usuário.

Loader

transform: rotate(0 - 360deg)

É criado usando @keyframes para fazer um elemento girar continuamente com transform: rotate(), simulando o carregamento. Esse efeito é aplicado a um círculo feito com bordas (border), onde uma parte é destacada para dar a impressão de movimento. A propriedade animation controla a velocidade e a repetição, fazendo o loader girar de forma infinita até que o carregamento termine.
